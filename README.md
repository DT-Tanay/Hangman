# CodeAlpha_HangmanGame

**CodeAlpha Python Programming Internship - Task 1**

A text-based Hangman game. The computer picks a random word from a list of 5 predefined words and you guess it one letter at a time. You lose after **6 incorrect guesses**.

## Run
```bash
python hangman.py
```
No external libraries needed (Python 3.8+).

## Features
- Random word from 5 predefined words
- ASCII-art hangman that grows with each wrong guess
- Input validation (single letters only, no repeated guesses)
- Play-again option with a running score

## Concepts used
`random`, `while` loop, `if-else`, strings, lists, functions
